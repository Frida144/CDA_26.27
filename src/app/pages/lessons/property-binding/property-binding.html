🔗 Property Binding & Attribute Binding

Angular permet de lier des données du composant à des éléments HTML. Deux grandes familles :

  • Property Binding : liaison à une propriété DOM.
  • Attribute Binding : liaison à un attribut HTML standard ou custom.

Syntaxe commune : [property]="expression" ou [attr.attribut]="expression".

1️⃣ Exemple : Property Binding

Code : <img [src]="imageUrl">

Code : <button [disabled]="buttonDisabled">

Code : <input [placeholder]="inputPlaceholder">

2️⃣ Exemple : Attribute Binding

Certains attributs HTML n’ont pas de propriétés DOM correspondantes ou sont custom. Dans ce cas, on utilise [attr.attribut].

Code : <button [attr.aria-label]="ariaLabel" [attr.data-custom]="customAttr">

💡 Différence Property vs Attribute Binding

  • Property Binding agit sur l’objet DOM directement → plus performant, recommandé.
  • Attribute Binding agit sur l’attribut HTML → utile pour aria-* ou data-*.
  • Si possible, privilégier Property Binding.

✅ Bonnes pratiques

  • Préparer vos variables dans le .ts pour ne pas surcharger le template.
  • Pour les attributs spéciaux, utiliser [attr.nom].
