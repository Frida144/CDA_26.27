Les variables d'environnement

Les variables d’environnement permettent de stocker des informations sensibles ou spécifiques à un environnement (clé API, URL de base, configuration...). Elles sont essentielles pour rendre vos applications sécurisées et configurables.

👉 Pourquoi utiliser des variables d'environnement ?

  • Ne pas exposer vos clés API directement dans le code.
  • Changer facilement la configuration entre développement, staging et production.
  • Améliorer la sécurité et la maintenabilité du projet.

⚡ Variables d’environnement avec Vite

Vite charge automatiquement les fichiers .env. Les variables doivent commencer par VITE_ pour être accessibles côté client. 

                # .env
VITE_API_URL=https://api.monsite.com
VITE_API_KEY=123456789

Ensuite, vous pouvez les utiliser dans votre code :

                // main.js
console.log(import.meta.env.VITE_API_URL);
console.log(import.meta.env.VITE_API_KEY);

🌱 Utiliser DotEnv dans Node.js

Pour un projet Node.js (hors Vite), on peut utiliser la librairie dotenv. 

                # .env
API_SECRET=mySuperSecretKey
              
                // server.js
import dotenv from "dotenv";
dotenv.config();

console.log(process.env.API_SECRET);

✅ Bonnes pratiques

  • Ne JAMAIS commiter votre fichier .env.
  • Créer un fichier .env.example pour documenter les variables nécessaires.
  • Utiliser des préfixes clairs (ex : VITE_ pour le frontend).
  • Changer les clés en cas de fuite.
