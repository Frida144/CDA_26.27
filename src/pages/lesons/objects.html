Les Objets en JavaScript

Les objets sont des collections de paires clé-valeur. Ils permettent de structurer des données complexes et de les organiser de manière logique.

👉 Pourquoi utiliser des objets ?

  • Stocker des données liées sous une seule entité (ex: les informations d'un utilisateur).
  • Modéliser des entités du monde réel.
  • Créer des structures de données complexes.
  • Organiser le code de manière plus sémantique et lisible.

⚡ Déclaration et accès aux propriétés

Un objet est défini par des accolades `{}` contenant des paires `clé: valeur`. Les clés sont des chaînes de caractères (ou des symboles) et les valeurs peuvent être de n'importe quel type. 

                
const utilisateur = {
  nom: 'Alice',
  age: 30,
  estConnecte: true,
  hobbies: ['lecture', 'voyage']
};

// Accès par notation point
console.log(utilisateur.nom);      // 'Alice'

// Accès par notation crochets (utile pour les clés dynamiques)
console.log(utilisateur['age']);   // 30

// Ajouter ou modifier une propriété
utilisateur.ville = 'Paris';
utilisateur.age = 31;
console.log(utilisateur);

🌱 Quelques méthodes d'objet utiles

Le constructeur `Object` fournit plusieurs méthodes statiques pour manipuler les objets.

Object.keys()

Renvoie un tableau contenant les noms des propriétés de l'objet.

                    
const utilisateur = { nom: 'Bob', age: 45 };
const cles = Object.keys(utilisateur);
console.log(cles); // ['nom', 'age']

Object.values()

Renvoie un tableau contenant les valeurs des propriétés de l'objet.

                    
const utilisateur = { nom: 'Bob', age: 45 };
const valeurs = Object.values(utilisateur);
console.log(valeurs); // ['Bob', 45]

Object.entries()

Renvoie un tableau de paires `[clé, valeur]` pour chaque propriété.

                    
const utilisateur = { nom: 'Bob', age: 45 };
const paires = Object.entries(utilisateur);
console.log(paires); // [['nom', 'Bob'], ['age', 45]]

✅ Bonnes pratiques

  • Utilisez des noms de clés clairs et descriptifs.
  • Préférez la notation point (`objet.propriete`) lorsque c'est possible pour plus de lisibilité.
  • Pour parcourir les propriétés d'un objet, vous pouvez utiliser une boucle `for...in` ou itérer sur les tableaux renvoyés par `Object.keys()`, `Object.values()` ou `Object.entries()`.
