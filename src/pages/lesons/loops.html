Les boucles en JavaScript

Les boucles sont des structures de contrôle qui permettent d'exécuter un bloc de code de manière répétée. Elles sont essentielles pour automatiser des tâches sur des collections de données.

👉 Pourquoi utiliser des boucles ?

  • Parcourir les éléments d'un tableau ou d'un objet.
  • Exécuter une tâche un nombre de fois défini.
  • Automatiser des processus répétitifs pour éviter la duplication de code.

⚡ Les boucles de base : for et while

for

La boucle `for` est la plus courante. Elle a une syntaxe claire pour l'initialisation, la condition et l'incrémentation.

                    
for (let i = 0; i < 3; i++) {
  console.log('Répétition n°' + i);
}
// Affiche :
// Répétition n°0
// Répétition n°1
// Répétition n°2

while

La boucle `while` s'exécute tant qu'une condition reste vraie. Faites attention aux boucles infinies !

                    
let compteur = 0;
while (compteur < 3) {
  console.log('Compteur : ' + compteur);
  compteur++; // Ne pas oublier l'incrémentation
}
// Affiche :
// Compteur : 0
// Compteur : 1
// Compteur : 2

🌱 Boucles pour les collections (tableaux & objets)

forEach (pour les tableaux)

Une méthode de tableau très pratique pour itérer sur chaque élément sans gérer d'index.

                    
const fruits = ['pomme', 'banane', 'orange'];
fruits.forEach(fruit => {
  console.log(fruit);
});
// Affiche : 'pomme', 'banane', 'orange'

for...of (pour les itérables)

La meilleure solution pour parcourir les éléments d'un tableau ou d'une chaîne de caractères.

                    
const fruits = ['pomme', 'banane', 'orange'];
for (const fruit of fruits) {
  console.log(fruit);
}

for...in (pour les objets)

Utilisée pour parcourir les propriétés d'un objet. Elle renvoie les clés.

                    
const utilisateur = { nom: 'Alice', age: 30 };
for (const cle in utilisateur) {
  console.log(cle + ': ' + utilisateur[cle]);
}
// Affiche : 'nom: Alice', 'age: 30'

map() (pour les tableaux)

Permet de créer un **nouveau tableau** en transformant chaque élément. C'est plus qu'une simple boucle, c'est une méthode de transformation.

                    
const nombres = [1, 2, 3];
const doubles = nombres.map(nombre => nombre * 2);
console.log(doubles); // [2, 4, 6]

✅ Bonnes pratiques

  • Pour les tableaux, préférez `forEach`, `for...of` ou `map()` à la boucle `for` classique pour plus de clarté. (mais moins performant que for sur des grand ensemble de données
  • Utilisez `for...in` uniquement pour les objets.
  • Assurez-vous toujours qu'une boucle `while` a une condition d'arrêt pour éviter une boucle infinie.
  • Le `map()` est le choix par excellence quand vous devez créer un nouveau tableau basé sur un existant.
